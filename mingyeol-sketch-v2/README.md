# 민결 키링 — 새 치수 스케치 기반 모델

사용자가 제공한 `reference-sketch.png`를 기준으로 별도 폴더에서 다시 제작했습니다. 기존 `mingyeol-rounded` 모델 파일은 변경하지 않았습니다.

## 반영한 형상

- 귀, 얼굴, 양손, 머리 리본, 좌우 하트, 하단 리본과 매듭, 리본 아래의 두 발
- 귀와 얼굴은 접합부 홈 없이 한 덩어리의 연속된 양각 표면으로 연결
- 한글 민결과 곡선 배치된 영문 MINGYEOL은 이미지 내부 글자 윤곽에서 추출
- 도면에서 열린 선으로 표현된 ㄹ의 틈은 실제 출력 형상에 맞게 연결 방향을 구분하여 보정
- 둥근 양각 장식, 눈·코·입의 얕은 음각, 평평한 뒷면
- 얼굴은 납작한 타원 대신 도면의 둥근 이마와 볼 윤곽으로 구성하고, 아래쪽이 이름판과 손 뒤에 가려지는 형태로 보정

## 치수 해석

도면의 치수 표기와 픽셀 비율이 서로 완전히 일치하지 않아, 최종 모델은 도면 그림 자체의 가로·세로 비율을 따릅니다.

- 기준 그림 외곽: 가로 x=384~1108, 세로 y=85~893 (고리 포함)
- 최종 가로: 45.0mm
- 최종 전체 세로: 45 × 808 / 724 = 약 50.221mm (고리 포함)
- 가로:세로 비율: 약 0.896:1
- 고리 구멍: 설계 직경 3.0mm, 실제 메시 측정값은 `print-validation.json` 참고
- 완성 최대 두께: 3.0mm, 바탕 약 1.8mm
- 도면의 40mm 높이 표기와 R2/R2.5/R3/R4/R6 표기를 모두 치수 구속한 정밀 CAD 모델은 아닙니다.

## 결과물

- `mingyeol-sketch-v2.stl`: 슬라이서용 STL, 단위 mm
- `mingyeol-sketch-v2.3mf`: 모델 3MF, 프린터별 슬라이싱 설정 미포함
- `mingyeol-sketch-v2.solidcraft`: SolidCraft에서 열 수 있는 메시 모델
- `preview-top.png`, `preview-iso.png`: SolidCraft MCP로 촬영한 실제 모델 렌더
- `print-validation.json`: 최종 STL 검증 결과

윤곽 추출과 거리장 기반 곡면 메시를 생성한 뒤 SolidCraft MCP의 `file.insert_mesh`, `save`, `export`, `screenshot`으로 모델을 저장하고 검증했습니다. SolidCraft 파일은 삼각형 메시이며 네이티브 파라메트릭 피처 모델은 아닙니다. STEP는 제공하지 않습니다.

## 출력

평평한 뒷면을 베드에 놓고 장식 면을 위로 향하게 합니다. 서포트 없이 출력할 수 있는 형태입니다. PLA/PETG, 0.12~0.16mm 레이어를 시작점으로 권장합니다. 작은 글씨와 좁은 틈은 0.2mm 노즐에서 더 선명합니다. 단색 모델이며 여러 색 출력에는 슬라이서의 별도 색상 설정이나 도색이 필요합니다.

최종 STL에서 밀폐된 표면, 일관된 면 방향, 연결된 몸체 1개를 확인했습니다. 실제 출력 및 고리 내구성은 미검증입니다.

## 재생성

`requirements.txt`의 패키지를 설치하고 `build_sketch.py`를 실행합니다. SolidCraft CLI 경로와 허용 경로는 `sc_client.py`에 지정되어 있습니다. 이미지에서 글자를 추출하므로 별도 폰트 파일은 필요하지 않습니다.
