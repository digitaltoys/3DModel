# 민결 토끼 키링 — 둥근 곡면 수정본

참고 이미지의 둥근 느낌에 맞춰 첫 모델을 수정했습니다.

- 약 45 × 58 × 3mm, 평평한 뒷면
- 받침 약 1.8mm, 글자와 리본 등의 최대 높이 약 3mm
- 귀는 1.8mm 바탕 위에 높이 약 2.45mm의 둥근 테두리를 겹친 2단 구조. 안쪽은 바탕 높이를 유지하며 바탕을 파지 않음
- 민결 글씨는 선택된 5번 검은고딕(Black Han Sans) 사용. 승인한 샘플과 같은 모서리 라운딩 적용: 기준 반경 1.14mm(샘플에서 약 20px), 짧은 모서리는 인접 변 길이에 맞게 제한. 별도의 획 확장 없음. 윗면은 둥근 양각 유지.
- 양손은 각각 가운데로 약 1.7mm 이동하고 받침 외곽에 손 형상을 포함해 잘림 방지
- 하단 리본과 MINGYEOL 글씨는 반경 43mm의 호를 따라 가운데가 올라가는 곡선으로 배치하고, 글자를 리본 높이의 중앙에 정렬
- 머리 리본은 곡선으로 된 두 날개와 중앙 매듭으로 재구성
- 영문 리본 뒤에 두 발을 추가해 아래로 둥근 발끝이 보이도록 배치
- 한글 이름 좌우에 작은 둥근 양각 하트를 대칭 배치
- 고리 구멍 약 3.3mm

## 파일과 제작 방식

`mingyeol-rounded.stl` 또는 `mingyeol-rounded.3mf`를 슬라이서에 불러오면 됩니다. 3MF는 모델 파일이며 프린터별 슬라이싱 설정은 포함하지 않습니다.

둥근 표면을 만드는 거리장과 메시를 생성한 뒤, SolidCraft MCP의 `file.insert_mesh`로 가져와 STL/3MF와 `mingyeol-rounded.solidcraft`를 저장하고 미리보기를 렌더링했습니다. SolidCraft 파일에는 삼각형 메시가 들어 있으며 첫 모델 같은 네이티브 돌출 피처 편집 모델은 아닙니다. STEP는 제공하지 않습니다.

`preview-top.png`와 `preview-iso.png`는 실제 SolidCraft 모델 렌더입니다. 색상은 미리보기용 단색이며 여러 색 출력은 별도 설정이 필요합니다.

## 출력과 검증

뒷면을 베드에 놓고 장식이 위로 향하게 출력합니다. PLA/PETG, 0.4mm 노즐, 0.12~0.16mm 레이어, 벽 3줄, 인필 100%를 시작점으로 권장합니다. 서포트는 필요하지 않습니다. 작은 영문은 0.2mm 노즐에서 더 선명합니다.

최종 SolidCraft 출력 STL에서 밀폐, 면 방향 일치, 연결된 몸체 1개를 확인했습니다. 실물 출력 및 고리 내구성은 미검증입니다. 이미지와 완전히 동일한 조형 복제품은 아닙니다.

## 재생성

`requirements.txt`의 Python 패키지를 설치하고 `build_rounded.py`를 실행합니다. MCP 실행 파일과 작업 경로는 `sc_client.py`에서 지정합니다. 영문에 사용한 Jua 글꼴의 라이선스는 `fonts/OFL.txt`, 한글 검은고딕의 라이선스는 `fonts/BlackHanSans-OFL.txt`입니다.
